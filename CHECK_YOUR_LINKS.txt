================================================================================
                   LINK MANAGER - HOW TO CHECK YOUR LINKS
================================================================================

QUICK ANSWER:
Open your Link Manager application in a web browser and authenticate with your
password. All your stored links will automatically appear in the card grid.

================================================================================
                              METHOD 1: USE THE APP
================================================================================

EASIEST WAY:
1. Open your Link Manager application URL in a browser
2. Enter your password when prompted
3. All links display in a card grid
4. Click any card to expand and see:
   - Full URL with working link
   - Copy button (copy URL to clipboard)
   - Edit button (modify name/URL)
   - Delete button (remove link)

SUPPORTED PLATFORMS:
The app recognizes and shows logos for:
- YouTube
- GitHub
- Twitter/X
- Instagram
- LinkedIn
- Facebook
- Generic links

DATABASE STATUS:
- If you see "No links yet" = database is empty
- If you see link cards = database contains those links

================================================================================
                        METHOD 2: PROGRAMMATIC ACCESS
================================================================================

RETRIEVE ALL LINKS IN CODE:

import { LinkORM, type LinkModel } from '@/sdk/database/orm/orm_link';

const linkORM = LinkORM.getInstance();
const allLinks = await linkORM.getAllLink();

console.log(`Found ${allLinks.length} link(s)`);

allLinks.forEach(link => {
  console.log(`${link.display_name}: ${link.url}`);
  console.log(`Created: ${new Date(parseInt(link.create_time) * 1000)}`);
  console.log(`Updated: ${new Date(parseInt(link.update_time) * 1000)}`);
});


CHECK DATABASE STATUS:

const linkORM = LinkORM.getInstance();
const links = await linkORM.getAllLink();

if (links.length === 0) {
  console.log('Database is empty');
} else {
  console.log(`Database contains ${links.length} link(s)`);
}


QUICK TABLE VIEW:

const linkORM = LinkORM.getInstance();
const links = await linkORM.getAllLink();
console.table(links);

================================================================================
                          YOUR LINK DATA STRUCTURE
================================================================================

Each stored link contains:

{
  id: "abc123xyz789",                    // Unique ID (auto-generated)
  display_name: "My Awesome Link",       // What you entered
  url: "https://example.com",            // The actual URL
  create_time: "1708123456",             // Unix timestamp (seconds)
  update_time: "1708123456",             // Last edit timestamp
  data_creator: "user-id-here",          // Who created it (read-only)
  data_updater: "user-id-here"           // Who last updated it (read-only)
}

================================================================================
                         AVAILABLE OPERATIONS
================================================================================

READ OPERATIONS:
  getAllLink()                          - Get all links
  getLinkById(id)                       - Get specific link by ID
  getLinkByDataCreator(userId)          - Get links by creator
  getLinkByDataUpdater(userId)          - Get links by updater
  listLink(filter, sort, paginate)      - Advanced querying

WRITE OPERATIONS:
  insertLink(data)                      - Add new links
  setLinkById(id, data)                 - Update existing link
  deleteLinkById(id)                    - Delete specific link
  deleteLinkByIDs(ids)                  - Batch delete links

ADMIN OPERATIONS:
  purgeAllLink()                        - Delete all links (careful!)

================================================================================
                              TROUBLESHOOTING
================================================================================

Q: I can't see the app
A: Make sure you have the correct application URL and your password is set

Q: I see "No links yet"
A: Your database is empty. Use "Add New Link" button to add your first link

Q: How do I add a link?
A: Click "Add New Link" button, enter a name and URL, then click "Add Link"

Q: Can I edit an existing link?
A: Yes! Expand any link card and click the "Edit" button

Q: How do I delete a link?
A: Expand any link card and click the "Delete" button (you'll be asked to confirm)

Q: Are my links safe?
A: Yes! They're stored in a secure cloud database with JWT authentication

Q: Can I backup my links?
A: You can export them by reading via the LinkORM class and saving to JSON
