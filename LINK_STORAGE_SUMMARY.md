# Link Manager - Complete Storage & Query Summary

## Quick Answer: How to See Your Links

**The easiest way to see all your stored links is to open the Link Manager application in your browser and authenticate with your password.** All links will automatically load and display in a card grid.

## Database Architecture

Your links are stored in the **Creao DataStore** - a cloud-based database service. The application communicates with it through the LinkORM class.

### Storage Location
- **Remote API**: `https://api-production.creao.ai`
- **Data Endpoint**: `/data/store/v1/all` (for retrieving all records)
- **ORM Implementation**: `/home/user/vite-template/src/sdk/database/orm/orm_link.ts`

### Link Data Fields
Every link record contains:

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique identifier (auto-generated by backend) |
| `display_name` | string | The name/title shown for the link |
| `url` | string | The actual URL/web address |
| `create_time` | string | Unix timestamp (10-digit) of creation |
| `update_time` | string | Unix timestamp (10-digit) of last update |
| `data_creator` | string | User ID who created the link (read-only) |
| `data_updater` | string | User ID who last updated the link (read-only) |

### Method 2: Programmatically via TypeScript/JavaScript

To retrieve all links in code:

```typescript
import { LinkORM, type LinkModel } from '@/sdk/database/orm/orm_link';

async function viewAllLinks() {
  const linkORM = LinkORM.getInstance();
  const allLinks: LinkModel[] = await linkORM.getAllLink();

  if (allLinks.length === 0) {
    console.log('No links stored');
  } else {
    console.log(`Found ${allLinks.length} link(s):`);
    allLinks.forEach(link => {
      console.log(`- ${link.display_name}: ${link.url}`);
    });
  }
}
```

### Method 3: Query Specific Links

The LinkORM supports various query methods:

```typescript
// Get a single link by ID
const link = await linkORM.getLinkById(linkId);

// Get all links created by a specific user
const userLinks = await linkORM.getLinkByDataCreator(userId);

// Advanced querying with filters, sorting, and pagination
const [links, pageInfo] = await linkORM.listLink(
  filter,  // Optional filter conditions
  sort,    // Optional sort configuration
  paginate // Optional pagination (page number, size)
);
```

## Complete ORM Operations Reference

### Read Operations

| Method | Parameters | Returns | Purpose |
|--------|-----------|---------|---------|
| `getAllLink()` | None | `Promise<LinkModel[]>` | Get all stored links |
| `getLinkById(id)` | `id: string` | `Promise<LinkModel[]>` | Get link by ID index |
| `getLinkByDataCreator(userId)` | `data_creator: string` | `Promise<LinkModel[]>` | Get links by creator |
| `getLinkByDataUpdater(userId)` | `data_updater: string` | `Promise<LinkModel[]>` | Get links by updater |
| `listLink(filter, sort, page)` | Optional filter/sort/page | `Promise<[LinkModel[], Page]>` | Advanced querying |

### Write Operations

| Method | Parameters | Returns | Purpose |
|--------|-----------|---------|---------|
| `insertLink(data)` | `data: LinkModel[]` | `Promise<LinkModel[]>` | Create new links |
| `setLinkById(id, data)` | `id: string, data: LinkModel` | `Promise<LinkModel[]>` | Update link by ID |
| `deleteLinkById(id)` | `id: string` | `Promise<void>` | Delete link by ID |
| `deleteLinkByIDs(ids)` | `ids: string[]` | `Promise<void>` | Batch delete links |

### Admin Operations

| Method | Parameters | Returns | Purpose |
|--------|-----------|---------|---------|
| `purgeAllLink()` | None | `Promise<void>` | Delete all links (careful!) |

## How the Application Uses Links

### Adding a Link
```typescript
// User fills form with name and URL
const result = await linkORM.insertLink([
  {
    url: newLinkUrl,
    display_name: newLinkName,
  } as LinkModel
]);
// Backend auto-fills: id, data_creator, create_time, update_time
```

### Updating a Link
```typescript
// User edits link details
const result = await linkORM.setLinkById(linkId, {
  ...existingLink,
  url: newUrl,
  display_name: newName,
  // Keep id, data_creator, create_time unchanged
});
// Backend auto-updates: data_updater, update_time
```

### Deleting a Link
```typescript
// User confirms deletion
await linkORM.deleteLinkById(linkId);
```

## Technical Implementation Details

### Client-Server Communication
- **Client**: `DataStoreClient` in `/src/sdk/database/orm/client.ts`
- **Authentication**: JWT tokens via `authApi` integration
- **Request Timeout**: 30 seconds per request
- **Base URL**: `https://api-production.creao.ai`

### Data Flow
1. Application calls `LinkORM.getInstance()`
2. LinkORM uses `DataStoreClient` singleton
3. Client makes authenticated HTTPS request to Creao API
4. API returns structured link data
5. Data is parsed and returned as `LinkModel[]` array

### Type Safety
All link operations are fully typed:
- `LinkModel` interface ensures type safety
- `LinkORM` class uses TypeScript generics
- No runtime type coercion or casting needed
