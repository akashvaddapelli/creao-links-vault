                              METHOD 1: SSH
================================================================================

STEP 1: Create GitHub Repo
  → https://github.com/new
  Name: link-manager
  Visibility: Private (recommended)
  ❌ DO NOT check "Add README"

STEP 2: Generate SSH Key
  ssh-keygen -t ed25519 -C "akashvaddapelli@gmail.com" -f ~/.ssh/gh_lm -N ""
  cat ~/.ssh/gh_lm.pub

STEP 3: Add Key to GitHub
  → https://github.com/settings/ssh/new
  Title: Link Manager
  Key: [paste output from Step 2]

STEP 4: Push
  git remote add origin git@github.com:YOUR_USERNAME/link-manager.git
  GIT_SSH_COMMAND="ssh -i ~/.ssh/gh_lm" git push -u origin main

DONE! Check: https://github.com/YOUR_USERNAME/link-manager

================================================================================
                            METHOD 2: HTTPS
================================================================================

STEP 1: Create GitHub Repo
  → https://github.com/new
  Name: link-manager
  Visibility: Private (recommended)
  ❌ DO NOT check "Add README"

STEP 2: Get Token
  → https://github.com/settings/tokens/new
  Note: Link Manager Push
  Scope: ✅ repo
  Copy the token (starts with ghp_)

STEP 3: Push
  git remote add origin https://github.com/YOUR_USERNAME/link-manager.git
  git push -u origin main
  Username: YOUR_USERNAME
  Password: [paste token from Step 2]

DONE! Check: https://github.com/YOUR_USERNAME/link-manager
