## 🚀 Quick Push Guide

### 3 Simple Steps:

#### 1️⃣ Create GitHub Repository

Go to: **https://github.com/new**

Settings:
- **Name:** `personal-link-manager` (or your choice)
- **Private:** ✅ Recommended
- **DO NOT check:** "Add README", "Add .gitignore", or "Choose license"

Click: **"Create repository"**

---

#### 2️⃣ Copy Commands from GitHub

After creating, GitHub shows you commands. They look like:

```bash
git remote add origin https://github.com/YOUR-USERNAME/personal-link-manager.git
git push -u origin main
```

**Copy these commands** (they'll have YOUR username automatically)

---

#### 3️⃣ Run in Terminal

Paste and run those commands in your terminal:

```bash
# Example (use the commands GitHub gives you):
git remote add origin https://github.com/akashv/personal-link-manager.git
git push -u origin main
```

**Done!** 🎉 Your code is now on GitHub.

## 🔐 Authentication

When pushing, GitHub will ask for:
- **Username:** Your GitHub username
- **Password:** Use a **Personal Access Token**

**Get Token:**
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Check: `repo` scope
4. Copy token and use as password
