How to use: This page helps you inspect what links are currently stored in your Link Manager database. The actual application interface is at your main application URL where you can add, edit, and delete links with a user-friendly interface.

About Your Link Manager

Your Link Manager stores links in a cloud database managed by Creao. Here's what you need to know:

  1. Storage: All links are stored in a remote Creao DataStore at api-production.creao.ai
  2. Each Link Contains:
    • Display Name - The title/label you give the link
    • URL - The actual web address
    • ID - Unique identifier (auto-generated)
    • Timestamps - When it was created and last updated
    • Creator/Updater - User IDs tracking who made changes
  3. Database File: The ORM implementation is at src/sdk/database/orm/orm_link.ts
  4. Main Application: All management (add/edit/delete) happens through the main Link Manager UI
API Details:
  • API Endpoint: https://api-production.creao.ai/data/store/v1/all
  • Request Timeout: 30 seconds
  • Authentication: JWT tokens managed automatically
