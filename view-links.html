📋 Where Are Your Links?

Your Links Are Stored In:

Database: Creao Cloud DataStore

API Endpoint: https://api-production.creao.ai

Namespace: 01987547fc6c72ecb453bd2736bd4ea0

Entity: Link (ID: 102019b6141e88672548fc9655f0d56014d)

ORM File: src/sdk/database/orm/orm_link.ts

How to View Your Links:

  1. Easiest Way: Open your Link Manager app in a browser and log in with password 9014094534.v
  2. Programmatically: Use LinkORM.getInstance().getAllLink() in your code
  3. This Page: This is a reference page - the actual app shows your links when you log in

Each Link Contains:

  • display_name - The custom name you gave it
  • url - The actual web address
  • id - Unique identifier (auto-generated)
  • create_time - When you created it
  • update_time - When you last edited it
  • data_creator - Your user ID
  • data_updater - Last updater's user ID

📍 To See Your Actual Links:

Step 1: Run your Link Manager application

Step 2: Enter password: 9014094534.v

Step 3: All your links will appear as cards on the page

Step 4: Click any card to expand and see the full URL, copy it, edit it, or delete it

If you see "No links yet" when you log in, it means your database is currently empty and you can start adding links!

💻 Programmatic Access

To retrieve all links in your code, use:

import { LinkORM } from "@/sdk/database/orm/orm_link";

const linkORM = LinkORM.getInstance();
const allLinks = await linkORM.getAllLink();

console.log("Total links:", allLinks.length);
allLinks.forEach(link => {
  console.log(`${link.display_name}: ${link.url}`);
});
